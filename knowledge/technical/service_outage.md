# Service outage

Check the official status page before declaring an outage. Record the affected
feature, region, first observed time, and whether multiple users are impacted.
If an incident is posted, share the incident link and advise the customer to
monitor it for updates; do not promise a restoration time.

If no incident is posted, try a private browser window and a second network to
separate a local issue from a service issue. Escalate suspected widespread
impact with timestamps and request identifiers.

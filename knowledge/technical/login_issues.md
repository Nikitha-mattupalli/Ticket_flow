# Login issues

Confirm the user is signing in with the correct email address and the expected
authentication method (password, Google, or Microsoft). Ask them to retry in a
private browser window and clear site cookies if the login page loops.

Do not ask for a password, one-time code, recovery code, or API key. After
several failed attempts, the account may be temporarily rate-limited; wait 15
minutes before retrying. Escalate when the user no longer controls the account
email, sees an unexplained MFA prompt, or still cannot sign in after a password
reset.

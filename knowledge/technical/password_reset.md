# Password reset

Use the Forgot password link and enter the account email. Check spam and
filtered folders, then allow up to ten minutes for delivery. Only the newest
reset link should be used; older links may be invalidated.

Never request the user's password or reset token. Escalate if the email does
not arrive after a second request, the account email is inaccessible, or the
reset link reports that it is invalid immediately after being issued.
